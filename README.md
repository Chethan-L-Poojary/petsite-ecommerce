# 🐾 PetSite E-commerce Website

## 📌 About the Project

PetSite is an online pet e-commerce website developed to make purchasing pet products easier and more convenient. Users can browse different categories of pet products, view available items, add products to their shopping cart, and place orders.

The website also provides an admin section to manage products, suppliers, customers, orders, and stock.

## ✨ Features

### User Features
- User Registration and Login
- User Authentication
- Browse Pet Products
- Different Product Categories
- Add Products to Cart
- Place Orders
- Payment Management
- Order History
- Forgot Password and Reset Password

### Admin Features
- Admin Login
- Admin Dashboard
- Add, Update and Manage Products
- Manage Suppliers
- View Customer Details
- Manage Orders
- Update Order Status
- Manage Product Stock

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Local Server:** XAMPP
- **Code Editor:** Visual Studio Code

## 💻 Software Requirements

- XAMPP Server
- Web Browser (Google Chrome recommended)
- Visual Studio Code
- MySQL Database

## ⚙️ Installation and Setup

1. Download or clone this repository.

     `git clone https://github.com/Chethan-L-Poojary/petsite-ecommerce.git`

3. Place the project folder inside the XAMPP `htdocs` directory.

4. Start Apache and MySQL from the XAMPP Control Panel.

5. Open phpMyAdmin in your browser:

   `http://localhost/phpmyadmin`

6. Create a MySQL database for the project.

7. Import the provided database SQL file into phpMyAdmin.

8. Configure the database connection details in the PHP database connection file.

9. Open the website in your browser:

   `http://localhost/project/`
